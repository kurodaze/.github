KuroDaze builds efficient software within the Linux ecosystem, lean on resources and a easy to use.

## Projects

**[togewire](https://github.com/kurodaze/togewire)**: Self-hosted Spotify listen-along. Archive what you play, or share a live stream anyone can join from a browser, no Premium required.

**[togematch](https://github.com/kurodaze/togematch)**: Finds a track's official audio upload on YouTube from a Spotify link or a search, skipping music videos, live versions and re-uploads. A Rust library, plus an HTTP API and CLI for the local network.

**[musicart](https://github.com/kurodaze/musicart)**: Self-hosted Discord music bot. Runs several bots in one process and plays YouTube and Spotify links in the best audio quality available, with EQ presets or your own EQ.

**[KDNX Jellyfin OIDC](https://github.com/kurodaze/kdnx-jellyfin-oidc)**: Single sign-on for Jellyfin through the KDNX OIDC provider, including session lifetime enforcement and client app support.
